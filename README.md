## Завдання 1. Найменше значення

У двійковому дереві пошуку значення лівого піддерева менші за значення
поточного вузла. Тому для пошуку мінімуму потрібно рухатися від кореня
ліворуч, доки не закінчаться ліві дочірні вузли.

Функція `find_min(root)` повертає значення крайнього лівого вузла.
Для порожнього дерева вона повертає `None`.

Часова складність — **O(h)**, де `h` — висота дерева;
додаткова пам'ять — **O(1)**. Для збалансованого дерева час становить
O(log n), а для виродженого — O(n). Використане дерево автоматично
не балансується.

## Завдання 2. Сума всіх значень

Функція `sum_tree(root)` додає значення поточного вузла до сум його
лівого та правого піддерев. Для порожнього піддерева сума дорівнює нулю.
Кожен вузол обробляється один раз.

Часова складність — **O(n)**, додаткова пам'ять для рекурсії — **O(h)**.
Повторювані значення зберігаються в окремих вузлах і враховуються в сумі.
Під час вставлення однакові значення спрямовуються у праве піддерево.

## Завдання 3. З'єднання кабелів

Застосовано жадібний алгоритм із мінімальною купою:

1. Побудувати купу з довжин кабелів за допомогою `heapq.heapify`.
2. Вилучити два найкоротші кабелі через `heapq.heappop`.
3. Додати суму їхніх довжин до загальних витрат.
4. Повернути об'єднаний кабель у купу через `heapq.heappush`.
5. Повторювати, доки не залишиться один кабель.

Чому цей вибір оптимальний: послідовність з'єднань можна подати як двійкове
дерево, де початкові кабелі — листки. Кожна довжина додається до витрат
стільки разів, скільки з'єднань лежить на шляху від її листка до кореня.
Два найкоротші кабелі можна розташувати у парі найглибших сусідніх листків
без збільшення витрат. Після їх об'єднання залишається така сама задача
з меншою кількістю кабелів. Це обґрунтовує повторний вибір двох найкоротших.

Для `[4, 3, 2, 6]` порядок такий:

```text
2 + 3 = 5
4 + 5 = 9
6 + 9 = 15
Загальні витрати: 5 + 9 + 15 = 29
```

**15** — довжина кінцевого кабелю, а **29** — сума витрат на всі з'єднання.
Функція повертає саме **29**. Параметр `show_steps=True` додатково виводить
порядок з'єднань у консоль.

Функція працює з копією вхідного списку. Для порожнього списку або одного
кабелю вона повертає `0`, оскільки з'єднання не потрібні. Приклади
використовують невід'ємні цілі довжини; від'ємні довжини відхиляються.

Побудова купи займає O(n), кожне з n − 1 з'єднань — O(log n).
Загальна часова складність — **O(n log n)**, додаткова пам'ять — **O(n)**.

## Результат запуску

Для дерева, побудованого зі значень `[10, 5, 15, 3, 7, 12, 18]`:

- найменше значення — **3**;
- сума всіх значень — **70**.

Для кабелів `[4, 3, 2, 6]` мінімальні загальні витрати — **29**.
